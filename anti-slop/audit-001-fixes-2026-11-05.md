## Bukti interaksi

- Masuk menggunakan akun owner demo: halaman ringkasan terbuka; judul tab sesuai route.
- Pengaturan: Tab mencapai picker sampul, Enter membukanya, Escape menutup dan mengembalikan fokus. Tab berikutnya mencapai picker logo; urutan Enter/Escape berhasil juga.
- Tab pengaturan: panah kanan memindahkan Profil ke Jam lalu Notifikasi; isi dan pilihan tab berubah bersamaan.
- Notifikasi: kedua kontrol disabled, masing-masing berlabel belum tersedia.
- Koordinat: kondisi kosong tidak memiliki peta/pin ilustratif; input sementara `0,0` menghasilkan tautan yang sesuai. Tombol Batal mengembalikan data semula; tidak menekan Simpan.
- Analitik: DevTools memblokir hanya API daftar restoran. Halaman menampilkan `Daftar restoran belum dapat dimuat` dan tombol retry. Setelah pola dihapus, retry memulihkan statistik serta label data sintetis.
- Customer: akun dan dua listing sintetis terpisah dibuat di ReplateLocal, pada restoran `[DEMO SINTETIS] Audit UI`. Tidak membuat pesanan atau checkout. Listing tanpa foto menampilkan placeholder di marketplace, detail, dan cart.
- Add-to-cart: item pertama masuk; request pemeriksaan item pertama kemudian diblokir ketika mencoba item kedua. UI melaporkan kegagalan sambil mempertahankan pilihan sebelumnya.
- Cart: dengan request masih diblokir, UI menampilkan error dan retry tanpa mengklaim cart kosong. Setelah pola dihapus, retry menampilkan item pertama, jumlah satu, total Rp 10.000. Tombol tambah mengubah jumlah menjadi dua dan total Rp 20.000; tombol kurang mengembalikannya menjadi satu.
- Mobile: cart diperiksa pada viewport responsive 390 × 844; placeholder, nama menu, harga, jumlah, total, tombol pesanan, dan navigasi bawah tetap terbaca. Desktop diperiksa untuk autentikasi, pengaturan, dan analitik.
- Semua pola pemblokiran sementara dihapus dan blocking dinonaktifkan. Device toolbar dimatikan dan DevTools ditutup setelah pengujian.

- Lint workspace dan TypeScript frontend lulus.

## Delivery Gate untuk perubahan ini

- **Hard Gate: PASS dalam lingkup temuan yang diperbaiki.** Jalur gagal cart dan analitik diuji; akses keyboard picker diuji; foto dan lokasi tidak dipresentasikan secara keliru; kontras diukur; panel/tab, judul, copy, dan loading hero diperiksa. Tidak ada pesan atau berkas pengguna yang dikirim. Tidak ada fitur yang disisipkan lewat script patch source/CSS.
- **Purpose-Gate: PASS dalam lingkup perubahan.** Ikon grafik menunjukkan analitik; placeholder netral menandai foto belum tersedia; outline menunjukkan fokus keyboard. Tidak menambah dekorasi, statistik, testimoni, atau animasi baru.
- **Liveliness: PASS dengan arah yang dipertahankan.** ENERGY 2 / RHYTHM 2 / MOTION 2 sebagai acuan audit; warna hijau/krem, motif daun, foto makanan yang benar, tipografi dan gerak ringan tetap menjadi identitas. Kejujuran placeholder dipertahankan tanpa menggantinya dengan foto produk fiktif.
- **Craftsmanship & Quality Locks: PASS untuk perbaikan terpilih.** Logika cart dipakai ulang melalui satu rekonsiliasi yang diuji; foto melalui satu komponen; tab melalui komponen existing; CTA menyebut aksi pendaftaran. Ketahanan error dan navigasi keyboard diverifikasi pada interaksi di atas.

Gate ini tidak menyatakan seluruh aplikasi telah diaudit ulang tanpa batas. Safari/perangkat fisik, seluruh ukuran viewport, seluruh alur screen reader, checkout, pengiriman SMTP, notifikasi produksi, upload berkas sampai tersimpan, pengujian keamanan, dan deployment VPS tidak diperiksa ulang. Console mencatat warning request yang sengaja diblokir saat fault injection; warning itu bukan kegagalan aplikasi yang disembunyikan.

Data demo pengujian tetap tersedia pada database lokal; profil/produksi restoran pengguna tidak diubah. Penghapusan gambar palet, file generated, konfigurasi lokal, dan perubahan README yang sudah ada dipertahankan.
